# Evento App

Aplicación web para organizar eventos entre amigos o grupos: creación de eventos, registro de participantes, confirmación de asistencia y control de pagos.

## Funcionalidades

- Registro, login y recuperación de contraseña
- Alta y baja de eventos
- Confirmación de asistencia de los participantes
- Registro de pagos con comprobante, y listado de pagos pendientes
- Recordatorios de pagos
- Resumen por evento y reporte mensual
- Transferencia de la administración de un evento

## Tecnologías

- PHP (backend)
- MySQL
- HTML, CSS y JavaScript (frontend)

## Cómo ejecutarlo

1. Instalar XAMPP (o similar) e iniciar Apache y MySQL.
2. Copiar la carpeta del proyecto en `htdocs`.
3. Crear la base de datos y ajustar los datos de conexión en `conexion.php`.
4. Abrir `http://localhost/evento_app/login.html`.

> Los datos que aparecen en el proyecto son de demostración.
